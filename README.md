# Socratic Seminar Notecatcher
## Online/Technology-Enhanced Communication vs. In-Person Communication

A student-facing GitHub Pages activity that guides students through research, comparison/contrast analysis, Socratic question development, and seminar preparation.

### Features
- 8 guided Tasks
- Student responses autosave in the browser using localStorage
- At least two student-selected research sources
- Article title, author/organization, publication, date, and direct URL
- Article summary in the student's own words
- Evidence/finding analysis
- Explicit explanation of how each article connects to the seminar topic
- Compare/contrast organizer
- Socratic question scaffolding
- Seminar readiness checklist
- Seminar-ready PDF generated in the browser
- Clickable article links in the generated PDF
- Full notecatcher printing option

### Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` (and this README if desired).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`.
6. Save and wait for GitHub to provide the Pages URL.

### Important
The activity uses the jsPDF library from a CDN to generate PDFs, so students need internet access when generating the PDF. Their typed responses are stored locally on the device/browser they are using and are not submitted to a server.

The "Clear Saved Work" button deletes locally saved answers from that browser.
